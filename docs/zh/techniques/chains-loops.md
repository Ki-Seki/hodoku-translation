# 链与环 (Chains and Loops)

## 概述

- 最基础和最强大的技巧
- 每个数独都可以只用链和唯数解决
- 链 = 从前提出发的推理序列

## 链接与推理

- **弱链接**："如果a为真则b为假" -- 两者都可以为假
- **强链接**："如果a为假则b为真" -- 需要格子中恰好2个候选数或宫中恰好2个
- 强链接总是也是弱链接；可以替代弱链接但反之不行

## 组链接 (Group Links)

- 使用宫交叉在多个候选数之间推理
- 组强链接："如果r3c12都不是5，r3c7必须是5"
- 组弱链接："如果r3c12中有一个是5，r3c7不能是5"
- 图片：`/examples/lc101.png`、`/examples/gn101.png`

## 链中的ALS

- ALS = 一个宫中N个格子有N+1个候选数
- 作为强链接节点运作：消除一个候选数将其转换为锁集

## 链与网

- 链：每个链接只依赖于紧接的前一步
- 网：链接依赖于更早的步骤，或分支重新汇合

## 记法系统

- 强制链：`r2c7<>4 => r2c7=5 => r2c2=4`
- 完美环：`r2c7 -5- r2c2 -4- r3c1 -5- r6c1`（弱=`-x-`，强=`=x=`）
- AIC（尤里卡）：`(4=5)r2c7-(5=4)r2c2-(4=5)r3c1-(5=4)r6c1`

## 远程数对 (Remote Pair)

- 最简单的链技巧：只有相同两个候选数的双值格子
- 最少4个格子；能看到两个相反极性链格子的外部格子 -> 消除两个数字
- 示例1：4格子链，数字4、5。r6c7能看到两个端点 -> r6c7不等于4,5
- 示例2：8格子链，数字2、8
- 可用简单着色复制
- 图片：`/examples/rp01.png`、`/examples/rp02.png`

## X链 (X-Chain)

- 只用一个数字的链；必须以强链接开始和结束
- 消除：从能看到两个端点的格子中消除链数字
- 4格X链 = 涡轮鱼（摩天楼、双线风筝、ER）
- 示例1（数字7）：r1c2=7=r1c9-7-r2c8=7=r7c8-7-r7c3=7=r4c3。从r4c2消除7
- 示例2（数字3）：证明r4c2或r6c5是3。从r6c123消除3
- 图片：`/examples/x01.png`、`/examples/x02.png`

## XY链 (XY-Chain)

- 只有双值格子，任意候选数对；必须以同一数字的强链接开始和结束
- 所有强链接在格子内；所有弱链接在格子间
- 示例1：3-r7c4-9-r5c4-8-r5c6-2-r2c6-3。一个端点必须是3
- 示例2：8-r6c5-4-r8c5-1-r8c4-9-r3c4-8
- 图片：`/examples/xyc01.png`、`/examples/xyc02.png`

## 完美环/AIC

### 传播规则

1. 节点有两个强链接 -> 数字必须不同
2. 节点有两个弱链接 -> 格子必须是双值且数字不同
3. 一个弱一个强 -> 数字必须相同

### 不连续完美环

- 起始格子处的矛盾
- **消除候选数**：以弱链接开始，以不同数字的强链接结束 -> 矛盾。图片：`/examples/dnl01.png`
- **填入候选数**：以强链接开始，以相同数字的强链接结束 -> 必须为真。图片：`/examples/dnl02.png`

### AIC 1型

- 以同一数字的强链接开始和结束 -> 数字必须在一个端点格子中
- 从能看到两个端点的格子消除
- 可以是自噬的
- 图片：`/examples/aic101.png`、`/examples/aic102.png`

### AIC 2型

- 以不同数字的强链接在能看到对方的格子中开始和结束
- 从起始格子消除结束数字；从结束格子消除起始数字
- 图片：`/examples/aic201.png`、`/examples/aic202.png`

### 连续完美环 / AIC环

- 环闭合无矛盾；所有弱链接变成强链接
- 消除提供弱链接的宫/格子中的所有额外候选数
- 图片：`/examples/cnl01.png`、`/examples/cnl02.png`

## 分组完美环/AIC

- 与标准相同但使用组链接
- 图片：`/examples/gdnl01.png`、`/examples/gcnl01.png`、`/examples/gaic01.png`、`/examples/gaic02.png`

## 组节点与ALS

- ALS节点增加显著力量（HoDoKu从v1.2默认禁用）
- 在连续环中，剩余ALS候选数被锁定 -> 额外消除
- 图片：`/examples/gdnlals01.png`、`/examples/gcnlals01.png`、`/examples/gaic1als01.png`、`/examples/gaic1als02.png`
