# 鳍鱼/刺身鱼 (Finned/Sashimi Fish)

## 鳍鱼/刺身 X-Wing

鳍X-Wing是常规X-Wing，其中一个或多个基础候选数未被覆盖集覆盖。只有能看到所有鳍的覆盖候选数（且不是基础候选数）可以被消除。当所有鳍为假时剩余的鱼是不完整的（或退化的），鳍鱼就变成了刺身鱼。

![鳍X-Wing示例](/examples/fbf201.png)

左边的示例：X-Wing在r24/c35中。鳍是r2c1中的额外基础候选数（不在覆盖集c35中）。如果鳍为假，常规X-Wing从r35c3和r5c5中消除9。如果鳍为真，它从r1c1、r2c35和r3c3中消除9。消除是两个集合的交集——只有r3c3在两者中，所以r3c3被消除。

![刺身X-Wing示例](/examples/sbf201.png)

右边的示例：c36/r37有两个鳍在r89c3。如果鳍为假，X-Wing仍然存在，但它是退化的（可以用r3c3和r7c6中的唯数替代）。这种退化性使其成为刺身。消除是r7c1——唯一能看到两个鳍的覆盖候选数。

## 鳍鱼/刺身剑鱼

这与鳍/刺身X-Wing的工作方式完全相同，只是有三个基础/覆盖集，而不是两个。

![鳍剑鱼示例](/examples/fbf301.png)

左边的示例：剑鱼c159/r357。鳍是r1c9（剩余的基础格子）。没有鳍时的可能消除是r3c7、r5c3、r7c6。只有r3c7能看到鳍（同一宫），所以r3c7被消除。

![刺身剑鱼示例](/examples/sbf301.png)

右边的示例：行中的剑鱼r269/c258。鳍是r6c4。看到鳍的覆盖格子是r45c5，所以两个消除：r45c5。没有鳍时，r6c2中有一个唯数，因此是刺身。

## 鳍鱼/刺身水母

在剑鱼基础上增加另一个基础/覆盖集组合就得到了鳍/刺身水母。

![鳍水母示例](/examples/fbf401.png)

左边的示例：水母r2479/c1348。鳍是r4c9。看到鳍的覆盖格子是r56c8。如果鳍为假，它退化为剑鱼（r479/c134），从r26c3中消除9。由于退化性，这也可以称为刺身。

![刺身水母示例](/examples/sbf401.png)

右边的示例：水母r1469/c1289。鳍是r9c3。消除是r7c12和r8c12。没有鳍时，r9c9中有一个唯数，因此是刺身。

## 更大的鳍鱼/刺身鱼

对于更大的鳍/刺身鱼，存在一个互补鱼产生相同的消除。搜索超过水母大小的鱼因此是不必要的。

## 关键消除逻辑

所有尺寸的核心推理遵循相同的两案例逻辑：如果鳍为假，标准鱼消除适用。如果鳍为真，它消除其行/列/宫中的候选数。可操作的消除是交集——在两种情况下都会被消除的候选数，意味着它们必须看到所有鳍并且是覆盖候选数（不是基础候选数）。
