# 解题技巧总览

以下列出了 HoDoKu 中所有可用的解题技巧，按难度从低到高排列。大多数报纸上的谜题只需使用**唯数**和**交叉**即可解决；竞赛级谜题可能需要用到**链**甚至**最后手段**等高级技巧。掌握更多技巧并不意味着必须使用它们——许多高级玩家更喜欢用最简单的技巧来解决谜题，以获得最大的解题乐趣。

**记法说明：**

- `r1c5` = 第1行第5列
- `r3c79` = 第3行第7列和第9列
- `b5` = 第5宫
