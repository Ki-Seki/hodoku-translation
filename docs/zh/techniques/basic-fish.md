# 基础鱼 (Basic Fish)

## 概述

使用基本的行/列约束消除候选数。不是每个交叉点都需要鱼数字，但每个基础集和覆盖集至少包含一个。

## X-Wing（2基础集 / 2覆盖集）

两行作为基础，两列作为覆盖（或反之），单个数字。

**示例1：** 基础行2、5；鱼数字5；候选数r2c58和r5c58；覆盖列5、8；消除r4c5中的5。

**逻辑：** 如果r2c5=5 → r5c8=5；如果r2c8=5 → r5c5=5。无论如何r4c5≠5。

![X-Wing示例1](/examples/bf201.png)
![X-Wing示例2](/examples/bf202.png)

## 剑鱼 (Swordfish)（3基础 / 3覆盖）

与X-Wing相同但有3个基础集和3个覆盖集。

**示例1：** 基础行1、2、9；覆盖列1、5、8；数字2。

**示例2：** 基础r2、4、7；覆盖c2、3、5；数字4。

![剑鱼示例1](/examples/bf301.png)
![剑鱼示例2](/examples/bf302.png)

## 水母 (Jellyfish)（4基础 / 4覆盖）

扩展到4个基础集和4个覆盖集。

**示例1：** 基础r3、4、6、7；覆盖c1、2、5、9；数字7。

**示例2：** 基础r1、3、6、7；覆盖c2、5、8、9；数字7。

![水母示例1](/examples/bf401.png)
![水母示例2](/examples/bf402.png)

## 更大的基础鱼

可能但不必要 — 对于任何更大的鱼，总是存在互补的更小鱼。
