# 基础鱼 (Basic Fish)

本页介绍使用基本行/列约束消除候选数的数独捕鱼技巧。技巧从2集到4集模式递进。所有示例都建立在鱼（概述）部分解释的概念之上。不是每个基础集和覆盖集之间的交叉都需要包含鱼数字，但每个基础集和每个覆盖集必须至少包含一个鱼数字。

## X-Wing（2基础集 / 2覆盖集）

X-Wing使用两行作为基础集，两列作为覆盖集（或反之），针对单个数字。两行基础行中该数字的所有候选数必须落在覆盖列内。覆盖集中不在基础集中的候选数可以被消除。

![X-Wing示例1](/examples/bf201.png)

左边的示例：基础集是行2和5，鱼数字是5。候选数位置是r2c58和r5c58。覆盖集是列5和8。消除的是r4c5中的5（在覆盖列中但不在基础行中）。

![X-Wing示例2](/examples/bf202.png)

右边的示例：基础集是列1和5，覆盖集是行2和5。

消除逻辑：行2和5都只有两个候选数5。如果r2c5=5，则r2c8和r5c5不能是5。这迫使r5c8=5。反之，如果r2c8=5，则r5c5=5。要么r2c5要么r5c5必须是5，所以r4c5不能是5。

## 剑鱼 (Swordfish)（3基础集 / 3覆盖集）

剑鱼使用与X-Wing相同的原理，但有三个基础集和三个覆盖集，而不是两个。

![剑鱼示例1](/examples/bf301.png)

左边的示例：基础集是行1、2和9。覆盖集是列1、5和8。鱼数字是2。消除的是r7c1和r6c8中的候选数2（覆盖候选数不在基础集中）。

![剑鱼示例2](/examples/bf302.png)

右边的示例：基础集是r2、r4、r7。覆盖集是c2、c3、c5。鱼数字是4。消除包括从r3c235、r6c235、r8c235和r9c23中消除4。

## 水母 (Jellyfish)（4基础集 / 4覆盖集）

水母将模式扩展到四个基础集和四个覆盖集。

![水母示例1](/examples/bf401.png)

左边的示例：基础集是r3、r4、r6、r7。覆盖集是c1、c2、c5、c9。鱼数字是7。消除包括所有标红的候选数（多个格子）。

![水母示例2](/examples/bf402.png)

右边的示例：基础集是r1、r3、r6、r7。覆盖集是c2、c5、c8、c9。鱼数字是7。两个水母示例都来自新数独玩家论坛的纯水母收藏。

## 更大的基础鱼

比水母更大的基础鱼当然是可能的，但没有必要：对于任何更大的鱼，总是存在一个互补的更小鱼。
