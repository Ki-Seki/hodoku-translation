# 翼 (Wings)

## XY翼 (XY-Wing)

XY翼作为短XY链的可识别模式运作。结构涉及三个格子：**枢轴**（包含候选数X和Y的双值格子）和两个**钳子**（"看到"枢轴的格子——一个持有候选数X和Z，另一个持有Y和Z，其中Z与X和Y不同）。Z从任何能看到两个钳子的格子中消除。推理是：如果枢轴等于X，则XZ钳子必须是Z；如果枢轴等于Y，则YZ钳子必须是Z。无论哪种方式，能看到两个钳子的格子都不能包含Z。

![XY翼示例1](/examples/xy01.png)

左边的示例：枢轴r1c3有候选数5（X）和7（Y）。钳子r1c6有5/2（X/Z），钳子r2c1有7/2（Y/Z）。结果：r2c6不能是2。

![XY翼示例2](/examples/xy02.png)

右边的示例：X=1，Y=6，Z=9；枢轴在r4c1，钳子在r4c4和r5c2。产生五个消除。

## XYZ翼 (XYZ-Wing)

增强的XY翼，其中枢轴包含所有三个候选数：X、Y和Z。因为Z可能存在于枢轴本身中，消除更加受限——Z只能从能看到两个钳子和枢轴的格子中消除。

![XYZ翼示例1](/examples/xyz01.png)

左边的示例：枢轴r7c2，钳子r2c2和r7c1。如果r7c2=4 => r2c2=7；如果r7c2=5 => r7c1=7；如果r7c2=7直接。在所有情况下r9c2 <> 7。

![XYZ翼示例2](/examples/xyz02.png)

右边的示例：4/7/6在r23c4和r3c7中 => r3c56 <> 6。具有更多候选数的扩展翼已被描述，但它们难以定位，HoDoKu不支持它们。

## W翼 (W-Wing)

W翼涉及两个双值格子共享相同的两个候选数，通过其中一个候选数上的强链接连接。另一个候选数可以从所有能看到两个双值格子的格子中消除。当一个数字在一个单元中只有两个可能位置时存在强链接——如果一个没有设置，另一个必须设置。

![W翼示例1](/examples/w01.png)

左边的示例：双值格子r4c4和r8c9都包含候选数5和9。列8中候选数9存在强链接（r4c8和r8c8）。强链接的一端看到r4c4，另一端看到r8c9。候选数5从所有能看到r4c4和r8c9的格子中消除。证明：列8中的两个9中必须有一个被放置。如果r4c8=9，则r4c4=5；如果r8c8=9，则r8c9=5。因此双值格子中必须有一个是5。

![W翼示例2](/examples/w02.png)

右边的示例：W翼4/1在r1c9和r8c7中，通过r18c3中1的强链接连接 => r123c7和r89c9 <> 4。
