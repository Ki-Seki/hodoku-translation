# 唯数 (Singles)

## 全显数 / 末位数 (Full House / Last Digit)

全显数是最简单的技巧：当一个宫、行或列中只剩下一个空格时，该空格中只能填入唯一缺失的数字。

![全显数示例1](/examples/fh01.png)

**示例：** 宫8只剩一个空格，唯一缺失的数字是6，因此 r9c6=6。

![全显数示例2](/examples/fh02.png)

**示例：** 行5缺失数字1。

---

## 隐性唯数 (Hidden Single)

对于某个数字和某个宫/行/列，如果只有一个格子可以填入该数字，则该格子为隐性唯数。该格子可能有多个候选数，但该数字"隐藏其中"。

![隐性唯数示例1](/examples/h101.png)

**示例1：** r3c4 有候选数 4、6、9。在行3中，数字6只能放在 r3c4 → 填入6。

![隐性唯数示例2](/examples/h102.png)

**示例2：** r6c4 是隐性唯数——数字3是行6、列4和宫5中唯一可能的位置。

### 交叉排除法

专注于一个数字和一个宫，想象画线穿过已包含该数字的行和列，即可找到隐性唯数。

![交叉排除法](/examples/h103.png)

### 过滤器技巧

使用过滤器可以轻松找到隐性唯数和锁定候选数。

![过滤器技巧](/examples/h104.png)

## 显性唯数 (Naked Single)

当一个格子只剩下一个可能的数字时，即为显性唯数。所有能"看到"该格子的格子（同行、同列、同宫）包含了除一个数字外的所有数字。

![显性唯数示例1](/examples/n101.png)

**示例1：** r6c7——检查所有能看到它的格子，发现它们包含了除6外的所有数字 → r6c7=6。

![显性唯数示例2](/examples/n102.png)

**示例2：** r3c3——在 r3c4 填入3（隐性唯数）后，r3c3 变成显性唯数。

---

## 如何找到它们

- 用铅笔标记时，隐性唯数相对容易发现。
- 显性唯数在铅笔标记下更容易发现（候选数已填入）。
- 在电脑辅助下，显性唯数很直接，但隐性唯数可能更难找。
