# 唯数 (Singles)

唯数是解决数独最基本的技巧。有三种类型：全显数、隐性唯数和显性唯数。

## 全显数 / 末位数 (Full House / Last Digit)

全显数是可以填入一个宫的最后一个数字。如果它是整个网格的最后一个数字，有时称为"末位数"。

![全显数示例1](/examples/fh01.png)

在上面左边的示例中，宫8只剩一个未填格子。唯一缺失的数字是6，因此r9c6必须是6。

![全显数示例2](/examples/fh02.png)

右边的示例中，全显数出现在行5：只缺失数字1。

## 隐性唯数 (Hidden Single)

隐性唯数意味着对于某个给定的数字和某个宫，只剩一个格子可以放置该数字。该格子本身还有多个候选数，因此正确的数字隐藏在其他候选数之中。

![隐性唯数示例1](/examples/h101.png)

看左边示例中的格子r3c4：根据规则，数字4、6和9都是可能的。但如果我们仔细观察行3，我们会注意到在这一行中数字6只能放在r3c4。r3c1、r3c2和r3c3被r2c3中的数字6阻塞，r3c6被r6c6中的数字6阻塞。这意味着6可以放在r3c4。

![隐性唯数示例2](/examples/h102.png)

在右边的示例中，可以在r6c4找到一个隐性唯数：数字3是行6、列4和宫5中唯一的3。

## 显性唯数 (Naked Single)

显性唯数意味着在一个特定的格子中只剩一个数字是可能的（最后一个剩余的候选数没有其他候选数可以隐藏，因此是"裸露的"）。该数字必须放入该格子。

![显性唯数示例1](/examples/n101.png)

左边的示例：看格子r6c7：它不是隐性唯数。行6在r6c4有另一个可能的6，列7和宫6在r5c7都有另一个可能的6。但当我们检查所有能看到r6c7的格子时，我们注意到它们包含了除6之外的所有数字。因此6是r6c7最后一个可能的候选数。

![显性唯数示例2](/examples/n102.png)

右边的数独中，在r3c4填入3（一个隐性唯数）解锁了r3c3中的显性唯数：它是那里的最后一个可能的数字，可以填入。

## 如何找到它们

找到全显数是不言自明的。隐性唯数和显性唯数则不太容易发现。它们很好地说明了为什么确定技巧的难度级别如此困难：当纸笔游戏时，隐性唯数容易找到，但发现显性唯数可能需要一些时间。当使用像HoDoKu这样自动跟踪剩余可能候选数的计算机程序时，找到显性唯数是微不足道的，但找到隐性唯数可能相当费力，因为网格中剩余的候选数太多（尤其是在游戏早期）。

手动游戏时，可以通过"交叉排除法"找到隐性唯数：专注于一个数字和一个宫。想象画线穿过所有已经设置了该数字的行和列（请只在脑海中进行）。如果只剩一个格子，该格子就是该数字的隐性唯数。

![交叉排除法示例](/examples/h103.png)

左边的图像展示了在宫5中对数字3使用该技巧：该宫中的所有格子都被已放置的数字3"阻塞"，r6c4是宫5中数字3的最后一个可能格子。

![过滤器示例](/examples/h104.png)

右边的图像展示了另一种可能性：使用过滤器。如果启用了过滤器，可以轻松找到唯数和锁定候选数的移动。

手动找到显性唯数需要填入所有可能的候选数，或者尝试有希望的格子（计算能看到目标格子的所有格子中的所有数字；如果只剩一个可能性，那就是显性唯数）。
