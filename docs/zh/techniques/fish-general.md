# 鱼 (Fish) — 概述

## 概述

鱼是单数字模式 — 只考虑同一数字的候选数。从简单的X-Wing到奇异的自噬鳍变异鲸鱼。

## 核心原理

1. 找到N个不重叠的基础集（宫/行/列），其中没有基础候选数出现在多个基础集中。
2. 搜索N个不重叠的覆盖集，覆盖所有基础候选数。
3. 任何不在基础集中的覆盖候选数可以被消除。
4. 每个基础集和覆盖集必须至少包含一个鱼数字。

## 尺寸

| 尺寸 | 名称 |
|------|------|
| 2 | X-Wing |
| 3 | 剑鱼 (Swordfish) |
| 4 | 水母 (Jellyfish) |
| 5 | 蠕虫 (Squirmbag) |
| 6 | 鲸鱼 (Whale) |
| 7 | 利维坦 (Leviathan) |

## 类型（基础集/覆盖集组合）

- **基础鱼：** 行/列与列/行配对
- **弗兰肯鱼：** 行和宫与列和宫配对
- **变异鱼：** 行、列、宫的任意组合

**记法示例：**

- `4 c39 r46` → 数字4的基础X-Wing
- `4 c39b8 r469` → 弗兰肯剑鱼
- `4 r159c9 c45b36` → 变异水母

## 鳍（外鳍）

当基础候选数未被覆盖集覆盖时 → 外鳍，鱼变成鳍鱼。

要么所有鳍为假（正常鱼消除），要么一个鳍为真（消除能看到鳍的候选数）。所有能看到所有鳍的可能消除可以执行。

## 刺身

一些退化鱼包含更小的有效鱼。当鳍阻止简单鱼运作时 → 刺身鱼。HoDoKu默认对所有非基础类型使用"鳍鱼"。

## 内鳍

当基础候选数出现在多个基础集中 → 内鳍。只能在弗兰肯或变异鱼中出现。人类非常难以定位。

## 自噬

当基础候选数被两个或更多覆盖集覆盖时 → 自噬消除。鱼"几乎在吃自己"。
