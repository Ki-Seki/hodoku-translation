# 杂项技巧 (Miscellaneous)

## Sue de Coq (SDC)

Sue de Coq是子集计数的一个变体，由昵称为"Sue de Coq"的用户在EnjoySudoku论坛上以"双区域不相交子集"的名称首次介绍。社区采用了发明者的昵称作为该技巧的名称。

### 基本变体

核心概念是找到行（或列）与宫交叉处的格子，包含2个格子有4个候选数，或3个格子有5个候选数。然后在交叉外的行中定位一个双值格子，其候选数完全来自交叉集，以及在宫中定位一个双值格子，其候选数也来自交叉集但与行格子中的不同。

所有行格子候选数从行的其余部分消除，所有宫格子候选数从宫的其余部分消除，来自行和宫集的任何交叉候选数也被消除。

![Sue de Coq示例1](/examples/sdc01.png)

左边的示例：交叉格子是r7c13，候选数{3459}。行格子是r7c7，候选数{45}。宫格子是r8c3，候选数{39}。消除：从行7的其余部分消除4和5；从宫的其余部分消除3和9。

逻辑是：交叉有4个候选数对应2个格子（多2个）。行格子移除一个可能性，剩3个候选数对应2个格子。宫格子移除另一个，剩恰好2个候选数对应2个格子。这产生两个重叠的锁集：{3,9}锁定在r7c13 + r8c3中（都在同一宫中，从宫消除）和{4,5}锁定在r7c13 + r7c7中（都在同一行中，从行消除）。

![Sue de Coq示例2](/examples/sdc02.png)

右边的示例：交叉格子是r789c9，候选数{24567}（3个格子，5个候选数）。列格子是r2c9，候选数{56}。宫格子是r9c7，候选数{27}。候选数4被锁定在交叉内，从宫和列中消除。

### 扩展类型

存在两个增强方向：有额外候选数的交叉格子（每个多余候选数需要在行/列或宫中找到一个额外格子）和有非交叉候选数的行/宫格子（每个多余候选数需要一个额外格子）。

关键限制：交叉中最多2个格子（可能第三个格子作为行/宫格子的一部分），相同的非交叉候选数可以同时出现在行格子和宫格子中。

![扩展Sue de Coq示例A](/examples/sdc04.png)

示例A：交叉是r46c8，候选数{3578}。列格子是r8c8，候选数{35}。宫格子是r4c7和r5c9，候选数{789}。增强：宫格子包含不在交叉中的候选数9，需要两个宫格子而不是一个。

![扩展Sue de Coq示例B](/examples/sdc03.png)

示例B：交叉是r456c1，候选数{123479}（6个候选数在3个格子中——多1个）。列格子是r89c1，候选数{234}（3个候选数在2个格子中）。宫集包含不在交叉中的额外候选数5。

![扩展Sue de Coq示例C](/examples/sdc05.png)

示例C：标准的4候选数在2格子中的变体。列格子和宫格子都包含不在交叉中的相同额外候选数：候选数1。

![扩展Sue de Coq示例D](/examples/sdc06.png)

示例D：展示了所有增强组合（5候选数在2格子中）。列4与宫2的交叉有3个未解格子，但只有r23c4形成候选数{13689}的交叉集；r1c4是宫格子的一部分。此SDC消除了13个候选数。
