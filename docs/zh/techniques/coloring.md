# 着色法 (Coloring)

## 概述

- 单数字解题技巧
- 找到目标数字只有两个候选数的宫/行/列 -> 强链接（共轭对）
- 每对中的两个候选数获得相反颜色
- 要么所有颜色1格子为真颜色2为假，要么反之
- 比手动搜索链更容易

## 简单着色（两种颜色）

### 颜色陷阱 (Color Trap)

- 能看到相反颜色格子的未着色格子 -> 消除该候选数
- 示例：数字3，r1c9能看到r1c4（颜色A）和r8c9（颜色B）。从r1c9消除3
- 图片：`/examples/sc01.png`

### 颜色包裹 (Color Wrap)

- 共享同一颜色的两个格子也在同一宫中 -> 该颜色必须为假，消除所有该颜色的格子
- 示例：数字8，r2c4和r4c4共享同一颜色和列4 -> 消除所有该颜色的候选数
- 图片：`/examples/sc02.png`

## 多重着色（多对颜色）

### 1型（颜色对之间的弱链接）

- 来自不同对的两个着色格子共享一个宫 -> 两个对的相反颜色必须包含真候选数
- 从能看到至少两个相反颜色格子的格子中消除
- 示例：数字1，r1c7（1b）和r2c9（2a）共享宫3 -> 从能看到1a和2b的格子消除
- 图片：`/examples/mc01.png`

### 2型（同一颜色看到另一对的相反颜色）

- 颜色1b的格子看到2b；另一个1b格子看到2a -> 所有1b格子被消除
- 示例：数字3，r6c2（1b）看到r6c9（2b）；r8c6（1b）看到r2c6（2a）-> 消除所有1b
- 图片：`/examples/mc02.png`

## 技术说明

- 多重着色等价于X链
- HoDoKu目前只支持两对颜色
