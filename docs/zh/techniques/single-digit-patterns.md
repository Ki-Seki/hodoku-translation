# 单数字模式 (Single Digit Patterns)

## 摩天楼 (Skyscraper)

摩天楼是一个简单模式，在数独中经常出现，容易发现。它是涡轮鱼的一种特殊形式，也可以看作是两个刺身X-Wing。

要找到摩天楼，专注于一个数字，找到两行（或列），每行（或列）恰好有两个该数字的候选数。如果其中两个候选数共享同一列（或行），则另外两个中必须有一个为真。所有能看到这两个非共享格子的候选数可以被消除。两个顶部格子必须在同一区域中才能消除。

![摩天楼示例1](/examples/sk01.png)

左边关于数字1的示例：列6在行1和5中有候选数，列9在行3和5中有候选数。r5c6和r5c9共享同一行（基础）。链推理是：如果r1c6不为真，则r5c6必须为真（强链接），r5c9不能为真（弱链接，同一行），r3c9必须为真（强链接）。由于r1c6和r3c9中总有一个为真，能看到两者的格子被消除：r1c78和r3c45中的数字1。

![摩天楼示例2](/examples/sk02.png)

右边的示例：数字4的顺时针旋转90度的摩天楼。

每个摩天楼都可以解释为两个重叠的刺身X-Wing。

## 双线风筝 (2-String Kite)

双线风筝是涡轮鱼的另一种特殊形式，在许多数独中常见。

要找到双线风筝，专注于一个数字，找到一行和一列，每行/列恰好有两个候选数（"线"）。行中的一个候选数和列中的一个候选数必须共享同一个宫。能看到另外两个（非共享）格子的候选数可以被消除。双线风筝的工作方式类似于摩天楼：线的两端之一必须为真。

![双线风筝示例1](/examples/2sk01.png)

左边关于数字5的示例：第一条线是列7（候选数r29c7），第二条线是行8（候选数r8c49）。端点r9c7和r8c9都在宫9中。如果r2c7为假，则r9c7为真，r8c9为假，r8c4为真。消除：r2c4（能看到r2c7和r8c4）不能是5。

![双线风筝示例2](/examples/2sk02.png)

右边的示例：数字9，线r6c16和r47c2，在宫4中连接。消除：r7c6不能是9。

### 双线风筝

有时同一个宫中的两个连接候选数可以连接到四条不同的线，同时形成两个双线风筝。这些消除两个不同的候选数。这两个双线风筝可以被认为是一个移动，可以称为双线风筝。

![双线风筝示例1](/examples/d2sk01.png)

左边关于数字1的示例：公共候选数r1c3和r3c1在宫1中。风筝1（r1c38/r36c1）从r6c8中消除1。风筝2（r3c19/r14c3）从r4c9中消除1。

![双线风筝示例2](/examples/d2sk02.png)

右边关于数字4的示例：公共候选数r7c2和r9c1在宫7中。风筝1（r29c1/r7c28）从r2c8中消除4。风筝2（r17c2/r9c19）从r1c9中消除4。

## 涡轮鱼 (Turbot Fish)

涡轮鱼实际上是一条链而不是鱼。它是一条恰好4个候选数长的X链。可以构建各种形状；其中一种类似于鱼的形状，给了这个技巧它的名字。涡轮鱼已经有点过时了，因为主要的涡轮模式现在有自己的命名分类：摩天楼、双线风筝和空矩形。

## 空矩形 (Empty Rectangle, ER)

如果一个候选数在宫中被限制在恰好一行和一列中，则剩余的格子形成空矩形。

![空矩形定义1](/examples/er01.png)

左边的定义示例：宫5中候选数9被限制在行4和列6中。ER格子是r5c45和r6c45。

![空矩形定义2](/examples/er02.png)

右边的定义示例：宫5中候选数1被限制在行4和列5中。ER格子是r5c46和r6c46。

要使用ER，找到共轭对（恰好有两个候选数的行或列）。共轭对中的一个候选数必须在形成ER的行（或列）中。如果ER的列（或行）包含一个能看到共轭对第二个候选数的候选数，则该候选数可以被消除。ER模式总是可以看作鳍变异X-Wing或分组完美环。

![空矩形示例1](/examples/er01.png)

左边关于数字9的示例：行4和列6在宫5中形成ER。r48c2形成共轭对。一端在ER行中（r4c2）；另一端能看到ER列中的候选数（r8c6）。消除：r8c6中的9。

![空矩形示例2](/examples/er02.png)

右边的示例：行4和列5形成ER，r7c59是共轭对。消除：r4c9中的4。

### 只有两个候选数的ER

当ER只包含两个候选数时，空矩形没有明确定义，但消除仍然有效。该移动可以被识别为涡轮鱼或X链。一些数独玩家不认为只有两个候选数的ER是有效的，因此HoDoKu只可选地支持它们。

![两个候选数的ER示例1](/examples/er201.png)
![两个候选数的ER示例2](/examples/er202.png)

### 双重空矩形

当被消除的候选数和共轭对的另一端也形成共轭对时，两个强链接都可以作为"共轭对"，产生两个消除。这称为双重空矩形。

![双重空矩形示例1](/examples/der01.png)

左边的示例：由行2和列3形成的ER。r6c35是共轭对，从r2c5中消除2。同时r26c5是共轭对，从r6c3中消除2。

![双重空矩形示例2](/examples/der02.png)

右边的示例：双重空矩形：b5中的9（r67c8/r7c48）从r6c8和r7c4中消除9。
