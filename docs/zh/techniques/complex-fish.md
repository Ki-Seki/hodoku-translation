# 复杂鱼 (Complex Fish)

## （鳍）弗兰肯鱼

至少一个基础集或覆盖集是宫。

**示例（弗兰肯水母）：** r125b7/c1257，消除r3c257、r4c12、r6c257≠8。

![弗兰肯水母示例](/examples/ff401.png)

**示例（鳍弗兰肯剑鱼）：** c34b6/r346，鳍r5c7，消除r3c8。

![鳍弗兰肯剑鱼示例](/examples/fff301.png)

**示例（鳍弗兰肯X-Wing）：** 行6 + 宫1 / 列3、5，鳍r2c1。也称为空矩形。

![鳍弗兰肯X-Wing示例](/examples/fff201.png)

**示例（自噬鳍弗兰肯剑鱼带内鳍）：** r15b3/c68b2，内鳍r1c89，自噬消除r1c6。

![自噬鳍弗兰肯剑鱼示例](/examples/fff302.png)

## （鳍）变异鱼

所有宫类型（行、列、宫）都在基础集和覆盖集中。

**示例（鳍变异X-Wing）：** r6+c2/c6+b4，鳍r7c2，消除r7c6。也称为双线风筝/涡轮鱼。

![鳍变异X-Wing示例](/examples/fmf201.png)

**示例（鳍变异水母）：** r16c47/c1b358，鳍r1c6和r7c7，消除r7c6。

![鳍变异水母示例](/examples/fmf401.png)

**示例（鳍变异鲸鱼）：** r35c89b49/r69c347b3，鳍fr4c1和efr9c8，消除r9c1≠4。

![鳍变异鲸鱼示例](/examples/fmf601.png)

## 暹罗鱼 (Siamese Fish)

两条相同类型的鱼占据相同格子但产生不同消除。

组成鱼必须是鳍鱼且在一个覆盖集中不同。最简单的形式（暹罗刺身X-Wing）= 摩天楼。

**示例（暹罗刺身剑鱼，数字1）：** r358/c259鳍r8c6 → 消除r7c5中的1；r358/c269鳍r5c5 → 消除r4c6中的1。

![暹罗刺身剑鱼示例](/examples/sfbf301.png)

**示例（暹罗刺身水母，数字8）：** 各两个鳍，两个消除。

![暹罗刺身水母示例](/examples/sfbf401.png)

需要在HoDoKu中启用"允许双重/暹罗"选项。
