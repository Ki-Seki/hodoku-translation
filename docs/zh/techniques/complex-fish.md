# 复杂鱼 (Complex Fish)

## （鳍）弗兰肯鱼

如果基础集或覆盖集中至少有一个是宫，则结果鱼称为弗兰肯鱼。

![弗兰肯水母示例](/examples/ff401.png)

示例展示了弗兰肯水母：r125b7 / c1257。消除是r3c257、r4c12、r6c257 <> 8。它类似于行中的基础水母，但第四个基础集是宫而不是行，使其成为弗兰肯鱼。

![鳍弗兰肯剑鱼示例](/examples/fff301.png)

此示例展示了鳍弗兰肯剑鱼：c34b6 / r346 — 三个基础/覆盖集（剑鱼），基础集中有宫（弗兰肯）。鳍是r5c7（剩余的基础格子）。消除是r3c8。

![鳍弗兰肯X-Wing示例](/examples/fff201.png)

此示例展示了鳍弗兰肯X-Wing：基础集是行6和宫1，覆盖集是列3和5。鳍是r2c1（未被覆盖）。此模式也称为空矩形。

![自噬鳍弗兰肯剑鱼带内鳍](/examples/fff302.png)

此示例展示了带内鳍的自噬鳍弗兰肯剑鱼：基础集是行1和5、宫3。覆盖集是列6和8、宫2。内鳍是r1c89（同时在基础集行1和基础集宫3中）。自噬消除是r1c6（包含在两个覆盖集——列6和宫2中，且能看到所有鳍）。

## （鳍）变异鱼

当所有可能的宫类型（行、列、宫）都允许在基础集和覆盖集中使用时，结果是变异鱼。

![鳍变异X-Wing示例](/examples/fmf201.png)

此示例展示了鳍变异X-Wing：基础集是行6和列2，覆盖集是列6和宫4。鳍是r7c2（未被覆盖）。消除是r7c6。这也称为双线风筝或涡轮鱼。

![鳍变异水母示例](/examples/fmf401.png)

此示例展示了鳍变异水母：r16c47 / c1b358。鳍是r1c6和r7c7。消除是r7c6。

![鳍变异鲸鱼示例](/examples/fmf601.png)

此示例展示了鳍变异鲸鱼：4 r35c89b49 / r69c347b3。鳍是fr4c1和efr9c8。消除是r9c1 <> 4。人类求解器不太可能找到这个——同样的消除可以通过分组完美环或强制链来实现。

## 暹罗鱼 (Siamese Fish)

两条相同类型的鱼占据相同的格子但产生不同的消除，组合成一个模式。组成鱼必须是鳍鱼，并且在一个覆盖集中不同。最简单的形式，暹罗刺身X-Wing，更广为人知的名字是摩天楼。

![暹罗刺身剑鱼示例](/examples/sfbf301.png)

此示例展示了数字1的暹罗刺身剑鱼：第一条鱼（r358 / c259，鳍在r8c6）从r7c5中消除1。第二条鱼（r358 / c269，鳍在r5c5）从r4c6中消除1。

![暹罗刺身水母示例](/examples/sfbf401.png)

此示例展示了数字8的暹罗刺身水母：每条鱼有两个鳍。第一条鱼（r4678 / c1689，鳍在r4c2和r6c2）从r5c1中消除8。第二条鱼（r4678 / c2689，鳍在r7c1和r8c1）从r9c2中消除8。

暹罗鱼需要在HoDoKu中启用"允许双重/暹罗"选项。
