# 交叉 (Intersections)

## 锁定候选数1型 — 指向 (Pointing)

如果在一个宫中，某个数字的所有候选数都集中在一行或一列中，则该数字不能出现在该行或列在该宫以外的位置。

![指向示例1](/examples/lc101.png)

看左边的示例：在宫1中，候选数5只能放在行3中。这意味着r3c1或r3c2中必须有一个是5，否则宫1中就没有5，这是不可能的。同时也意味着5可以从r3c7中消除，因为r3c7能看到r3c1和r3c2。该数独在此步之后可以用唯数解决。

![指向示例2](/examples/lc102.png)

锁定候选数移动最多可以消除6个候选数，如右边的示例所示：在宫8中，候选数1被锁定在行7中，因此可以从宫7和宫9与行7的交叉处消除。

## 锁定候选数2型 — 占据 (Claiming)

锁定候选数2型的工作方式恰好相反：如果在一行（或一列）中，某个数字的所有候选数都集中在一个宫中，则该候选数可以从该宫中其他所有格子中消除。

![占据示例1](/examples/lc201.png)

看左边的示例：在行2中，候选数7只能放在宫1中。它可以从宫1中不属于行2的所有格子中消除，在我们的例子中是r3c2。该数独在此步之后可以用唯数解决。

![占据示例2](/examples/lc202.png)

右边的示例展示了列中的锁定候选数移动：列6中所有的4都在宫2中。它们可以从该宫中其他任何位置消除，如图所示。

## 如何找到它们

![如何找到 — 指向](/examples/lc203.png)

锁定候选数移动通常通过在候选数被限制在一个宫中的一行或一列时插入铅笔标记来找到。看左边的示例：r7c2中的6阻塞了行7。在宫8中，候选数6因此只能放在列5中。这意味着在宫2或宫5的列5中都不能有6（锁定候选数1型）。

![如何找到 — 占据](/examples/lc204.png)

右边的示例展示了另一种变体：在宫8中，候选数6只能放在列4中，在宫9中只能放在列8中。由于在这两个宫中，候选数6都被限制在行7和行8中，在该通道的第三个宫（宫7）中，6必须在行9中（或者用上面的定义来说：6可以安全地从r8c2中消除）。

当对某个数字应用过滤器时，锁定候选数可以很容易地识别出来。有关示例，请参阅用户手册中的"使用过滤器"部分。
