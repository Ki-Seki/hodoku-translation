# 显性数集 (Naked Subsets)

## 显性数对 / 锁定数对 (Naked Pair / Locked Pair)

同一宫/行/列中的两个格子只包含相同的两个候选数 → 从该宫/行/列中其他格子消除这两个候选数。

**锁定数对：** 当配对格子跨越两个宫（如行和宫），消除适用于两个宫。

**示例1（行）：** r8c3和r8c4共享候选数3和9。从r8c2中消除3。

**示例2（宫）：** r4c5和r5c6在宫5中形成显性数对。

**锁定数对示例：** r3c79在行3和宫3中；行8和宫8中的数对。

## 显性数三 / 锁定数三 (Naked Triple / Locked Triple)

三个格子总共只包含三个候选数 → 从其他格子中消除。

不是每个格子都必须包含所有三个候选数，但总共不能超过三个。

**示例1（列）：** r2c2、r4c2、r5c2只包含3、6、9。从r1c2中消除6。

**示例2（宫）：** r3c45和r1c5在宫2中形成显性数三。

**锁定数三：** 格子跨越两个宫，消除适用于两者。

## 显性数四 (Naked Quadruple)

四个格子只包含四个候选数 → 从其他格子消除。

锁定数四不可能存在（交叉区域最多3个格子）。

**示例1（行）：** 候选数3、4、8、9在r8c1346中。

**示例2（宫）：** 候选数4、6、7、9在r8c2和r789c3中。

![显性数四示例1](/examples/n401.png)
![显性数四示例2](/examples/n402.png)

## 如何找到它们

最好在所有候选数都已铅笔标记后进行。相对容易发现且非常高效。
