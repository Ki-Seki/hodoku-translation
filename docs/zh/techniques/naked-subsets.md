# 显性数集 (Naked Subsets)

显性数集与隐性数集类似，唯一的区别在于它不是关于候选数被限制在格子中（如隐性数集），而是关于格子只包含一定数量的候选数。

## 显性数对 / 锁定数对 (Naked Pair / Locked Pair)

### 显性数对

如果你能找到两个格子，它们都在同一个宫中，且都只剩下相同的两个候选数，则可以从该宫中其他所有格子中消除这两个候选数。

![显性数对示例1](/examples/n201.png)

左边的示例：格子r8c3和r8c4都在同一个宫（行8）中，且都只剩下候选数3和9。由此立即可知，其中一个格子必须是3，另一个是9（具体哪个是哪个尚不清楚）。但我们可以确定地说r8c2不能是3。该数独在此步之后可以用唯数解决。

![显性数对示例2](/examples/n202.png)

右边的示例展示了宫中的显性数对：r4c5和r5c6在宫5中形成显性数对，从而从该宫中其他所有格子中消除候选数8和9。

### 锁定数对

如果形成显性数对的两个格子不仅限于一个宫，而是限于两个宫（一行和一宫，或一列和一宫），则它们有时称为锁定数对。候选数可以从两个宫中消除。

![锁定数对示例1](/examples/l201.png)

左边的示例中r3c79是行3和宫3中的锁定数对，因此从r3c3（行3）和r1c9（宫3）中消除2。

![锁定数对示例2](/examples/l202.png)

右边的示例展示了行8和宫8中的锁定数对，消除了18个候选数。

## 显性数三 / 锁定数三 (Naked Triple / Locked Triple)

### 显性数三

如果你能找到三个格子，它们都在同一个宫中，且都只剩下相同的三个候选数，则可以从该宫中其他所有格子中消除这些候选数。重要的是要注意，并非所有格子都必须包含所有三个候选数，但这三个格子中总共不能超过三个候选数。

![显性数三示例1](/examples/n301.png)

左边的示例：格子r2c2、r4c2和r5c2都在同一个宫（列2）中，总共只剩下候选数3、6和9。由此立即可知，其中一个格子必须是3，另一个是6，最后一个是9（具体哪个是哪个尚不清楚）。但我们可以确定地说r1c2不能是6。该数独在此步之后可以用唯数解决。

![显性数三示例2](/examples/n302.png)

右边的示例展示了宫中的显性数三：r3c45和r1c5在宫2中形成显性数三，从而从该宫中其他所有格子中消除候选数1、2和6。

### 锁定数三

如果形成显性数三的三个格子跨越两个宫，则它们形成锁定数三。消除适用于两个宫。

![锁定数三示例1](/examples/l301.png)

左边的示例：r789c5是列5和宫8中的锁定数三，从r8c4（宫8）和r2c5（列5）中消除9。

![锁定数三示例2](/examples/l302.png)

右边的示例：行5和宫6中关于5、6、7的锁定数三消除了18个候选数。

## 显性数四 (Naked Quadruple)

同一宫中的四个格子总共只包含四个候选数，则可以从其他所有格子中消除这些候选数。锁定数四不可能存在，因为行或列与宫之间的交叉最多只能有三个格子。

![显性数四示例1](/examples/n401.png)

左边的示例：候选数3、4、8、9在行8的r8c1346中，从r8c7中消除3和8，从r8c8中消除9。

![显性数四示例2](/examples/n402.png)

右边的示例：候选数4、6、7、9在宫7的r8c2和r789c3中。

## 如何找到它们

找到显性数集最好在所有剩余候选数都已铅笔标记到网格中后进行。由于构成数集的格子只能包含一定数量的候选数，它们相当容易发现且非常高效。
