# 隐性数集 (Hidden Subsets)

## 隐性数对 (Hidden Pair)

所有隐性数集的工作方式相同，唯一不同的是受影响的格子和候选数的数量。以隐性数对为例：如果你能在某个宫中找到两个格子，使得两个候选数在该宫中不出现在这两个格子之外，则这两个候选数必须放在这两个格子中。因此，所有其他候选数都可以被消除。

![隐性数对示例1](/examples/h201.png)

看左边示例中的列9：候选数1和9在该列中只出现在r5c9和r7c9中（通常缩写为r57c9）（它们也出现在行5、行7、宫6和宫9中，但这在这里不重要）。这两个格子中必须有一个是1，另一个是9。我们还不知道哪个是哪个，但我们知道r5c9不可能是6。

![隐性数对示例2](/examples/h202.png)

隐性数对可能被大量其他候选数所掩盖，如右边的示例所示：r1c12是候选数4和7的隐性数对（在这种情况下，它们隐藏在行1和宫1中），但这些格子中还有另外10个候选数，它们都可以被消除。

## 隐性数三 (Hidden Triple)

隐性数三的工作方式与隐性数对相同，只是有三个格子和三个候选数。

![隐性数三示例1](/examples/h301.png)

左边的示例展示了宫7中的隐性数三：候选数2、4和5在该宫中只出现在r8c2、r9c2和r9c3中。1可以从r9c2中消除，6可以从r9c3中消除，这解开了数独。

![隐性数三示例2](/examples/h302.png)

右边的示例很特殊，因为隐性数三是解答的第一步（初始状态没有唯数）。数三在列6（r468c6）中，候选数为2、5和6。数三之后只需要唯数就能解决数独。

## 隐性数四 (Hidden Quadruple)

隐性数四（4个候选数在4个格子中）相对罕见。不使用铅笔标记很难发现它们。

![隐性数四示例1](/examples/h401.png)

左边的示例展示了宫8中的隐性数四：格子r7c56和r8c56包含候选数2、4、5和8。

![隐性数四示例2](/examples/h402.png)

右边的示例展示了列9中的隐性数四：格子r1238c9包含候选数2、4、5和9。

## 如何找到它们

![如何找到隐性数对](/examples/h203.png)

当铅笔标记插入网格后，隐性数对变得相当容易发现。左边的示例展示了候选数4和8的铅笔标记：r3c46中的隐性数对立即可见。没有其他候选数可以进入这些格子之一。

找到更大的隐性数集需要相当好的短期记忆。许多玩家更喜欢在网格上应用铅笔标记后使用更大的显性数集而非更大的隐性数集。这完全是个人偏好。
