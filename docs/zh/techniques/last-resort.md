# 最后手段 (Methods of Last Resort)

## 模板法 (Templates)

模板法是一种单数字模式方法。在空网格上，恰好存在46,656种放置数字所有9个实例的可能性。每次放置一个数字实例时，不包含该格子的所有组合变得无效；每次另一个数字占据一个格子时，包含该格子的所有组合变得无效。

任何不在至少一个剩余模板中的格子中的数字可以被消除，在所有模板中都包含的格子中可以设置该数字。模板不是给人类玩家用的，但可以作为指标：如果不存在模板消除，则不存在单数字模式（使复杂鱼搜索变得不必要）。反之则不一定成立。

## 强制链 (Forcing Chain)

强制链是导致矛盾或真相以强制消除或放置的任何链的通用术语。任何不连续完美环或AIC都符合。单独不产生矛盾的链可以组合成多重强制链。

### 真相（多条链，相同结果）

如果一个前提必须为真，则结果必须为真。前提包括从格子的所有候选数出发的链（一个必须为真，至少一个为假），从一个宫中某数字的所有实例出发的链，以及从UR的所有额外数字出发的链。

![强制链示例](/examples/fcv01.png)

证明r1c7=4的示例：r4c4=1 => r8c4=6 => r6c8=6 => r1c8=3 => r1c7=4。r4c6=1 => r4c7=3 => r1c7=4。r4c7=1 => r5c8=5 => r1c8=3 => r1c7=4。含义：对于行4中数字1的每种可能放置，r1c7都是4。

三条链分别追踪如下：

![强制链真相 — 链1（r4c4=1 → r1c7=4）](/examples/fcv02.png)
![强制链真相 — 链2（r4c6=1 → r1c7=4）](/examples/fcv03.png)
![强制链真相 — 链3（r4c7=1 → r1c7=4）](/examples/fcv04.png)

### 矛盾（同一前提，不兼容的推论）

证明格子不能包含某数字，从宫中消除某数字的所有实例，在格子中设置多个数字，或在宫中设置某数字的多个实例。

## 强制网 (Forcing Net)

与强制链原理相同，但结构为网（允许分支）。被描述为真正的"最后手段"方法，只有非常有经验的玩家才能手动找到。

![强制网示例1](/examples/fnv01.png)

证明r1c2=5的示例：格子r7c2有三个候选数：6、7和9。所有都导致r1c2=5。

## 海怪鱼 (Kraken Fish)

将鱼与一条或多条链结合。通常使用不提供消除的鳍鱼，因为可能的消除无法看到所有鳍。

### 海怪鱼 1型

如果所有鳍为假，则所有可能的消除有效；如果鳍为真，则鱼被破坏，填入消除鳍同伴中所有鱼数字候选数。增强原则：如果一个可能的消除对所有可能的鳍都必须为假，则消除该候选数。

![海怪鱼1型示例1](/examples/kf101.png)

示例：基础是鳍弗兰肯X-Wing：2 r6b2 c57 fr6c2 fr6c9。链1（鳍r6c2 => r8c7）：r6c2 -2- ALS:r4c2,r5c13 -4- r2c1 =4= r2c6 -4- r8c6 =4= r8c7。

![海怪鱼1型示例2](/examples/kf102.png)

链2（鳍r6c9 => r8c7）：r6c9 -2- ALS:r13479c9 -8- ALS:r8c238 -2- r8c7。如果两个鳍都为假，鱼为真，消除r1c7、r5c7、r8c7。如果鳍r6c2为真，从r8c7中消除2（链1）。如果鳍r6c9为真，从r8c7中消除2（链2）。

### 海怪鱼 2型

鱼保证一个基础候选数在所有覆盖集中为真。从覆盖集中每个基础候选数出发的弱链接链加上每个鳍，都指向同一结论，形成强制链真相。

![海怪鱼2型示例](/examples/kf201.png)

示例：刺身X-Wing：4 r15 c12 fr1c7 fr1c9。覆盖集列2只有一个基础候选数（r5c2）；r3c2是覆盖候选数。链一起证明r5c9不能是7。

## 暴力破解 (Brute Force)

不算真正的技巧。在格子中放置一个数字并检查是否产生解。如果启用，每个数独都可以被解决。
